System Overview

How It Works

  1. Extract claims from input text
  2. Retrieve supporting evidence passages
  3. Verify each claim using evidence
  4. Report verdicts with citations

Verdict Types

  • SUPPORTED: Evidence supports the claim
  • REFUTED: Evidence contradicts the claim
  • NOT ENOUGH EVIDENCE: Insufficient data to decide
  • ABSTAIN: Cannot confidently classify

Local Inference

When in local mode, TruthGuard uses Ollama to run model inference on your machine. DeepSeek-R1 14B processes each claim against retrieved evidence.

Your input text is not sent to external servers or stored.
