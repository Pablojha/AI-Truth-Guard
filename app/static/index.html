About AI TruthGuard

How It Works

  1. Extract claims from input text
  2. Retrieve supporting evidence passages
  3. Verify each claim using evidence
  4. Report verdicts with citations

Verdict Types

  • SUPPORTED: Evidence supports the claim
  • REFUTED: Evidence contradicts the claim
  • INSUFFICIENT: Insufficient data to decide
  • ABSTAIN: Cannot confidently classify

Privacy & Security

When using local Ollama mode, all text is processed on your machine and never sent to external servers.

Your input text is not stored permanently. Only verification results are saved if you create an account.
